ZAKSS WORLD 5.4 — OFFLINE ANDROID EDITION

Fitur:
- Dunia open-world bergaya 2D/pseudo-3D, dependency-free
- Player + joystick, keyboard, lari, lompat, kamera swipe
- NPC manusia, hewan, kendaraan
- Kota, jalan, bangunan, pohon, batu
- Misi + uang
- HP + stamina + kecepatan
- Siang/malam dan hujan
- Minimap
- Pause
- Virtual landscape di browser + landscape native Android
- Tidak membutuhkan Three.js atau internet saat runtime

Build:
1. Ekstrak ZIP.
2. Buka folder di AndroidIDE/Android Studio.
3. Sync Gradle.
4. Build APK debug.
5. Install APK.

Catatan:
Versi ini sengaja tidak memakai library eksternal agar benar-benar offline. Untuk APK yang lebih berat/3D penuh, Three.js + aset lokal dapat ditambahkan pada versi berikutnya.
